# IWS image library

The 52 photos and logo reused from the old Interior Woodwork Specialist site
(https://www.interiorwoodworkspecialist.com), hand-picked and enhanced for the
new website. The same set is in the "IWS Website Photos" Google Drive folder.

Each photo was converted to sRGB, rotated correctly, given gentle auto-levels,
contrast and saturation, resized to a 2400px long edge, sharpened, and saved as
progressive JPEG at quality 88, with a descriptive filename.

| Folder | Count | Contents |
| --- | --- | --- |
| `kitchens/` | 30 | Kitchen cabinetry, islands, pantries |
| `bathrooms/` | 11 | Vanities and bathroom cabinetry |
| `built-ins-offices/` | 10 | Home offices, window seats, fireplace built-ins, detail shots |
| `logo/` | 1 | IWS mark, 2000x2000 |

`index.json` maps every file back to its source URL on the old site, the
WordPress media ID, and which old-site pages showed it.

Seven kitchen photos only existed at roughly 750x1000 on the old site. They
work for gallery cards and thumbnails but are too small for full-width hero
images: white-oak-shaker-island, white-kitchen-floating-shelves-brass-pulls,
white-kitchen-range-black-countertop, farmhouse-sink-window-black-countertop,
coffee-station-tall-cabinets-fridge, white-kitchen-floating-shelf-dark-floor,
white-kitchen-island-wicker-stools.

Personal and team photos, location map screenshots and the CNC video from the
old site were deliberately not kept. Replace these photos as IWS supplies new
photography.
